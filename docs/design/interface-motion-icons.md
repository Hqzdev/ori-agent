# Иконки и движение интерфейса

Общие компоненты Mac и iPhone находятся в `packages/OriDesign`.

- `OriGlyph` — каталог семантических иконок. `OriIcon` рисует только SVG из `OriIcons.xcassets`; прежние ключи SF Symbols преобразуются в контурные иконки этого каталога.
- Новые иконки: сетка 32×32, штрих 2.25, круглые окончания и соединения, небольшие залитые детали. Цвет задаёт вызывающий экран. Проверяйте поддержку ключа через `OriGlyph.resolve(symbol:)`.
- `OriIconSize`: 14 для подписей, 18 для контролов, 20 для навигации, 24 для крупных действий, 28 для иллюстраций. Размер не зависит от жирности текста.
- `OriInterfaceMotion`: нажатие 120 мс, короткая смена состояния 150 мс, обычный переход 220 мс, панель 280 мс. Пружины без отскока; сдвиг появляющегося контента — 6 pt.
- `OriPressFeedback` и `OriPlainButtonStyle` обеспечивают общий отклик кнопок. Приложения используют `KMotion` как короткое имя общих токенов.
- `kMotionRoot` объединяет системное уменьшение движения и предпочтение `blot.v3.reduceMotion`, публикует окружение и отключает анимации. На Mac настройка доступна в «Настройки → Общие → Движение».
- Анимация привязана к конкретным состояниям: выбранному разделу, видимости панели, списку идентификаторов сообщений или карточек. Не привязывайте анимацию контейнера к каждому изменению текста формы.
